## Run

```powershell
.\Browzen.exe
```

Use `Ctrl+T` for a new tab, `Ctrl+Shift+N` for Incognito, `Ctrl+L` for the address bar, and `F12` for Developer Tools.

Only the ready-to-run Windows executable is distributed in this repository.
