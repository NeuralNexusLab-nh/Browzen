# Web runtime components

Scramjet 1.1.0, bare-mux 2.1.9 and Acorn 8.15.0 retain their license texts in vendor/. They are not relicensed under Browzen's Apache-2.0 license.

Scramjet's package metadata declares MIT but its packaged LICENSE contains AGPL-3.0; this distribution preserves that license and does not assume the metadata overrides it. The modified guarded bundle combines the original vendor bundle with Acorn, source-normalizer.js and privacy-guard.js. Local modifications are provided in source form in this directory. The original scramjet.all.js is retained for comparison.

Upstream source: https://github.com/MercuryWorkshop/scramjet, https://github.com/MercuryWorkshop/bare-mux and https://github.com/acornjs/acorn. Review the upstream licenses before redistributing modified builds.
